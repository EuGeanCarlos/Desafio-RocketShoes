# RocketShoes — vitrine

Exercício de página de produto com imagens de tênis, preço e chamada de compra.

## Tecnologias

- HTML
- CSS

## Funcionalidades e utilização

Explore a vitrine e as imagens; o botão de compra não implementa pagamento ou checkout.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/Desafio-RocketShoes.git
cd Desafio-RocketShoes
python -m http.server 8000 --directory "."
```

Requer Python 3 para o servidor local. Abra http://localhost:8000.
